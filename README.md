# Danish Maqbool Bhat | Skill Nexis Week 1 Projects

This repository contains the three Week 1 assignments created by Danish Maqbool Bhat for the Skill Nexis Full Stack Developer (MERN) Internship:
1. Personal Portfolio Website (HTML + CSS)
2. React Components Practice (React components, props, state, events)
3. React Blog UI (JSON data, search, category filter)

## Requirements
- Node.js LTS and npm for the React projects
- A modern web browser

## Run the portfolio
Open `personal-portfolio/index.html` in your browser.

## Run React Components Practice
```bash
cd react-components
npm install
npm run dev
```

## Run React Blog UI
```bash
cd react-blog
npm install
npm run dev
```
